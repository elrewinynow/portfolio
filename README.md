# Elrewiny Portfolio Landing Page

صفحة Landing Page بسيطة لـ Ahmed Elrewiny.

## قبل الرفع على GitHub

افتح `index.html` وعدّل 3 أشياء:

1. رقم الهاتف:
   `+201000000000`

2. البريد:
   `your@email.com`

3. رابط LinkedIn:
   `https://www.linkedin.com/in/yourusername/`

ثم ارفع `index.html` و `style.css` إلى Repository الخاص بك.

> لو الـ Repository اسمه `portfolio`، فالرابط سيكون:
> `https://elrewinynow.github.io/portfolio/`
