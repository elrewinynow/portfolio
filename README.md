# Elrewiny Portfolio Landing Page

## بريف جلسة التشخيص

صفحة عربية من ست خطوات على `/Brief`، مع حفظ حقيقي في Cloudflare D1 عبر Worker مجاني. راجع [توثيق Cloudflare](docs/BRIEF-CLOUDFLARE.md) و[تقرير النشر](docs/BRIEF-RELEASE.md). تظل الصفحة الرئيسية وبقية الصفحات على Render كما هي. للمعاينة المحلية: Node >=24 ثم `npm start` وافتح `http://127.0.0.1:3000/Brief`. الاختبارات: `npm test`. لا توجد لوحة إدارة في هذه المرحلة.

صفحة Landing Page بسيطة لـ Ahmed Elrewiny.

## قبل الرفع على GitHub

افتح `index.html` وعدّل 3 أشياء:

1. رقم الهاتف:
   `+201000000000`

2. البريد:
   `your@email.com`

3. رابط LinkedIn:
   `https://www.linkedin.com/in/yourusername/`

ثم ارفع `index.html` و `style.css` إلى Repository الخاص بك.

> لو الـ Repository اسمه `portfolio`، فالرابط سيكون:
> `https://elrewinynow.github.io/portfolio/`
