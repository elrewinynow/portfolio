## المقترح المحدد

الحفاظ على خدمة الموقع الحالية والنطاق وDNS كما هي. إضافة Web Service واحدة باسم مقترح `elrewiny-brief-api` من المستودع نفسه، ووضع API فقط، مع قرص دائم 1 GB لملف SQLite. عنوانها الافتراضي من Render يُستخدم في `Brief/config.js`، دون subdomain مخصص. الواجهة تبقى على `https://elrewiny.com/Brief`.

التكلفة الاسترشادية الحالية من https://render.com/pricing : compute بـ$7/شهر + قرص بـ$0.25/GB/شهر = **$7.25/شهر** قبل الضرائب وأي استخدام زائد. يجب تأكيد السعر في شاشة الإنشاء قبل الإجراء المدفوع. لم يتم إنشاء موارد أو اختيار خطة مدفوعة.

الإعدادات المقترحة بعد الموافقة: Node 24+، `npm start`، `NODE_ENV=production`، `BRIEF_API_ONLY=true`، `PUBLIC_ORIGIN=https://elrewiny.com`، `BRIEF_DB_PATH=/var/data/briefs.sqlite`، سر عشوائي `BRIEF_SECRET` في إعدادات الخادم فقط، health path `/healthz`. لا تُنقل قاعدة الاختبار المحلية.

الكود جُهّز لاتصال cross-origin مع preflight لا يسمح إلا بـPOST وترويسات Content-Type وIdempotency-Key ومنشأ الموقع المحدد، دون cookies أو credentials. تشغيل API-only لا يخدم صفحات الموقع أو ملفاته. الاختبارات الأربع PASS محليًا، بينها رفض origins وطرق وترويسات غير مسموحة.
