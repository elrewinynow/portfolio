# داشبورد البريفات — مرحلة مستقلة بطلب المالك

الرابط: https://elrewiny-brief-dashboard.mrelrewiny.workers.dev

واجهة عربية RTL للبحث والفلترة وقراءة الإجابات وحفظ حالة المراجعة والملاحظات وتصدير CSV. لا يرسل تغيير الحالة رسالة للعميل ولا يؤكد حجزًا. لا يوجد حذف ردود.

## البيانات والحماية

نفس D1 `elrewiny-brief`، بربط خادمي فقط. `brief_submissions` يحتفظ بالإجابات الأصلية؛ جداول `brief_reviews` و`brief_review_commands` تفصل الملاحظات وتاريخ الأوامر غير القابل للتعديل. الحفظ ذري باستخدام trigger ومقارنة version، مع إعادة نفس النتيجة لنفس مفتاح الطلب ونفس النية، ورفض اختلافها. التحقق من الجلسة وصلاحية المفتاح داخل جملة الحفظ يمنع سباق إلغاء الصلاحية.

مفتاح مرور واحد للمالك. WebAuthn يتحقق من توقيع P-256 وRP ID وorigin والتحدي وuser verification. لا تُخزن بصمة أو PIN أو مفتاح خاص. جلسة عشوائية ساعة واحدة، بصمتها SHA-256 فقط في D1، والكوكي Secure/HttpOnly/SameSite=Strict. التحديات خمس دقائق ومستهلكة مرة واحدة ذريًا. تحديد محاولات الدخول: 40 لكل IP في الساعة و500 إجمالًا يوميًا، وعنوان IP محفوظ كبصمة مملحة فقط. لا CORS لقراءة الردود. تشغيل Worker قبل جميع الملفات يمنع تجاوز حماية البيانات عبر الأصول.

التسجيل الأول يتطلب رمزًا عشوائيًا مؤقتًا؛ `setup-owner.mjs` يرسل بصمته ووقت انتهائه عبر Wrangler secrets، ويحفظ الأصل في ذاكرة عملية محلية ساعة واحدة فقط. ينتقل للمتصفح داخل fragment ويُمسح من العنوان فور القراءة. بعد أول مفتاح يُغلق التسجيل حتى لو بقي الرمز صالحًا. التسجيل لا ينشئ جلسة؛ يجب إثبات المفتاح بالدخول. أنشئ المفتاح يدويًا في متصفحك واحفظه في مدير مفاتيح موثوق ومتزامن إن كنت تريد استخدام أجهزة أخرى. فقدان المفتاح يتطلب إجراء صيانة صريحًا ومراجعًا عبر حساب Cloudflare؛ لا توجد إعادة تعيين عامة أو كلمة مرور بديلة.

## التشغيل والنشر

من جذر portfolio، Node 24:

```powershell
npm ci
npm test
npm run build:dashboard
npm exec --yes --package=wrangler@4.168.0 -- wrangler d1 execute elrewiny-brief --remote --file dashboard/migration.sql
npm exec --yes --package=wrangler@4.168.0 -- wrangler deploy --config dashboard/wrangler.jsonc
node dashboard/setup-owner.mjs
```

خذ نسخة احتياطية قبل migration. الملف إضافي وقابل لإعادة التطبيق. لا تعدّل مخطط البريف الأصلي. بعد إعداد المالك أوقف عملية setup المحلية، واحذف SETUP_HASH وSETUP_EXPIRES من أسرار العامل كإجراء تنظيف. لا تحذف سجلات المفتاح أو التاريخ لتجاوز المصادقة. نشر Cloudflare مستقل عن Render؛ رفع GitHub وحده لا ينشر هذا العامل. لا تغيير DNS أو Subdomain أو إعداد Render. Workers Free وD1 الحاليان؛ لم يُفعّل Cloudflare Access بسبب طلب تفويض خصم تجاوزات في checkout.

للمعاينة الاصطناعية فقط: `node tests/dashboard-preview.mjs` على 127.0.0.1:3001. هذا harness يولد مفتاحًا اختباريًا ويثبت توقيعه عبر WebAuthn الحقيقي، ثم يرفق جلسة الاختبار محليًا. ليس جزءًا من كود العامل المنشور.

## تصدير Excel وPDF — 2026-11-26

- زر «تصدير Excel» ينشئ ملف XLSX فعليًا داخل متصفح المالك من الردود المطابقة للبحث والحالة، بحد 500 رد دون اقتطاع صامت. صف لكل بريف، أعمدة لجميع الأسئلة والحالة والملاحظات، اتجاه RTL وتثبيت العناوين وفلاتر. أرقام التواصل والقيم الشبيهة بالمعادلات محفوظة كنصوص. CSV ما زال متاحًا.

- المسارات الجديدة: /api/export.json و/api/briefs/:id/print. جميعها خلف نفس مصادقة المالك، مع no-store وCSP. يتم escape للنصوص في صفحة الطباعة. لا بيانات دخول أو روابط تحميل عامة ولا خدمات تحويل خارجية. لا تعديل مخطط أو بيانات D1 ولا DNS.
- ExcelJS 4.4.0 مع override لـuuid 11.1.1 لمعالجة تقرير الأمان؛ npm audit أظهر صفر ثغرات بعد التثبيت. الحزمة المولدة dashboard/public/excel-export.js مستبعدة من Git ويعيد npm run build:dashboard إنتاجها قبل النشر.
- PASS: مجموعات npm test الإحدى عشرة، بما فيها إعادة فتح XLSX للتحقق من العربي وأصفار الهاتف والنصوص الشبيهة بالمعادلات، حدود التصدير والفلاتر ورفض الوصول غير المسجل وHTML escaping.
- PASS: توليد PDF اصطناعي عبر محرك Chrome، A4 من صفحتين، وتحويل الصفحتين إلى PNG ومراجعتهما بصريًا: عربي واضح دون قص. الأدلة خارج المستودع في ../validation/exports/.
- PASS: الرابط الحي عرض زر Excel وأكّد تجهيز الملف. صفحة الطباعة الحية عرضت الإجابات وملاحظات السجل الاصطناعي. التحقق من اختيار Save as PDF يدويًا في نافذة المتصفح NOT RUN؛ أمر النقر الآلي انتهت مهلته، بينما توليد PDF بمحرك المتصفح نجح.
- نشر هذه الإضافة يقتصر على عامل الداشبورد الحالي. لا تغييرات للبريف العام أو إعدادات Render أو خطة مدفوعة.
